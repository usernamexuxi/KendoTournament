# 검도 대진표 프로그램 설계

- 작성일: 2026-11-12
- 상태: 개발자 검토 대기
- 공개 범위: **이 PC 안에서만 다룬다.** 원격 저장소·외부 서비스에 올리지 않고 다른 개발자와도 공유하지 않는다(개발자 지시).

표기 규칙: 출처 표시가 없는 결정은 개발자가 말한 것이다. 「*(설계자 판단)*」은 내가 정한 것이고, 「*(해석)*」은 개발자의 말을 내가 풀어 쓴 것이라 확인이 필요하다.

---

## 1. 무엇을, 왜

검도 경기 운영회는 대회 때마다 각 검도장에서 신청 문서를 받는다. 문서에는 출전 인원이 적혀 있고 대개 한글 파일이다. 운영자는 이 문서들을 보고 부문을 나눈 뒤 토너먼트 대진표를 손으로 짠다.

이 프로그램은 그 문서들을 불러와 아래 일을 대신하고, 인쇄용 대진표(한글 파일 + PDF)를 만든다.
- 명단을 모은다.
- 운영자가 정한 제약조건대로 부문을 나눈다.
- 같은 도장끼리 일찍 만나지 않게 대진을 짠다.

- **개발자:** 이 대화의 상대. 프로그램을 만들고 고쳐 나간다. 개발 PC 에는 한글 프로그램이 없다.
- **운영자:** 실제로 쓰는 사람. 윈도우 PC 한 대에 exe 로 설치해서 쓰고, 그 PC 에는 한글이 깔려 있다. 개발자가 아니므로 화면만 보고 쓸 수 있어야 한다.

## 2. 목표 · 비목표 · 실패 조건

**목표**
1. 워드·한글·PDF 신청 문서를 여러 개 한꺼번에 불러와 하나의 명단으로 만든다.
2. 운영자가 부문 제약조건을 정한다. 예: 초1 단독인지 초1~2 묶음인지, N명 미만이면 합친다.
3. 개인전·단체전 토너먼트를 무작위로 추첨하되 같은 도장끼리는 떨어뜨린다.
4. 자동으로 짠 대진을 운영자가 손으로 고친다.
5. A4 인쇄용 한글 파일(.hwpx)과 PDF 를 만든다.
6. 인터넷 없이 exe 하나로 설치해서 돌아간다.

**비목표 (이번 범위 아님)**
- 경기 결과 입력과 다음 라운드 진출 처리. 나중에 별도 기능으로 만든다.
- 코트(경기장) 배정, 경기 시간표 짜기
- 시드 배정
- 여러 PC 동시 사용, 네트워크, 계정·로그인

**실패 조건 (돌아가도 실패로 본다)**
- 같은 도장 선수끼리 1회전에서 붙었는데 운영자가 모른다.
- 문서에서 선수가 빠졌거나 잘못 읽혔는데 운영자가 모른 채 대진표가 나간다.
- 운영자 PC 의 한글에서 출력 파일이 열리지 않는다.
- 손으로 고친 대진이 프로그램을 다시 켜면 사라진다.

## 4. 사용 흐름

```
① 대회 만들기 → ② 문서 불러오기 → ③ 명단 확인·수정 → ④ 부문 설정 → ⑤ 대진 생성 → ⑥ 대진 수정 → ⑦ 출력
```

1. **대회 만들기:** 대회명, 대회 날짜(운영자가 설정), 범위(전국 또는 광명)를 정한다. 3위는 늘 공동 3위다(2026-11-12 개발자 지시로 3위 결정전 삭제).
2. **문서 불러오기:** 파일을 여러 개 고르거나 끌어다 놓는다. 허용 확장자는 `.docx` `.hwp` `.hwpx` `.pdf` 뿐이고, 다른 확장자는 이유를 보여 주고 거부한다.
   - 옛 워드 형식 `.doc` 는 「워드에서 .docx 로 다시 저장해 주세요」라고 안내하고 거부한다. *(설계자 판단)*
   - 글자가 없는 사진 PDF(스캔·팩스)는 오지 않는다(개발자 답변). 그런 PDF 가 들어오면 「읽지 못함」으로 알리고, 운영자가 명단 화면에 손으로 입력한다. 글자 인식(OCR)은 넣지 않는다.
3. **명단 확인·수정:** 읽은 선수를 표로 보여 준다. 칸은 도장명 · 이름 · 성별 · 학년(또는 나이) · 산출된 구분(초3, 중1, 성인 등) · 출처 파일이다. 운영자가 행을 고치고, 추가하고, 지울 수 있다. 다음 행은 강조한다.
   - 읽지 못한 칸이 있는 행
   - 나이로 학년을 추정한 행
   - 같은 도장 + 같은 이름이 중복된 행 (경고만 하고, 어떻게 할지는 운영자가 정한다)
4. **부문 설정:** 5장 규칙대로 부문을 만든다. 어느 부문에도 들지 않은 선수는 따로 목록으로 보여 준다.
5. **대진 생성:** 부문마다 6장 알고리즘으로 대진을 만든다.
6. **대진 수정:** 두 칸(선수·팀·부전승)을 골라 맞바꾼다. 같은 도장이 1회전에서 붙게 되면 경고하되 그대로 둘 수도 있다. 부문 단위로 다시 추첨할 수도 있다.
   - **대진을 만든 뒤 명단이 바뀌면** 빼기와 끼워 넣기로 처리한다.
     - 기권한 선수(팀)를 빼면 그 칸이 부전승이 된다.
     - 늦게 신청한 선수는 빈 부전승 칸에 끼워 넣는다. 같은 도장이 가장 늦게 만나는 칸을 먼저 추천하고, 운영자가 고른다.
     - 부전승 칸이 없으면 끼워 넣을 수 없다고 알리고, 「부문 다시 추첨」을 안내한다. 다시 추첨하면 손으로 고친 내용이 사라진다는 경고를 먼저 띄운다.
     - 나머지 대진과 손으로 고친 내용은 그대로 둔다.
   - 도장이 고친 문서를 다시 보내면 다시 불러온다. 이때 기존 명단과의 차이(추가·삭제·변경)를 보여 주고, 운영자가 반영할 것을 고른다. 반영은 위의 빼기·끼워 넣기로 한다. *(설계자 판단)*
7. **출력:** 부문을 골라 `.hwpx` 와 PDF 로 저장한다.

대회 전체(명단·부문·대진·수정 내역)는 대회 파일 하나에 저장하고, 다시 열면 그대로 이어서 작업한다. 자동 저장한다. *(설계자 판단)*

## 5. 명단과 부문

### 5.1 신청 문서에서 읽는 항목

| 항목 | 필수 | 비고 |
|---|---|---|
| 도장명 | 필수 | 문서 머리에 한 번만 적혀 있을 수도 있고, 행마다 있을 수도 있다 |
| 이름 | 필수 | |
| 성별 | 필수 | 남/여, 남자/여자, M/F 를 인식한다 |
| 학년 또는 나이 | 필수 | 학생은 보통 학년, 성인은 나이 |
| 지역 | 전국 대회만 | 대진표 표시용. 대진 규칙에는 쓰지 않는다 *(설계자 판단)* |
| 단체전 팀 | 단체전만 | 5.4 참고 |

**같은 도장 판정** *(설계자 판단)*: 도장명의 앞뒤 공백과 가운데 공백을 지운 문자열이 같으면 같은 도장으로 본다. 표기가 다른 같은 도장도 있다(예: 「○○검도관」과 「○○검도장」). 그래서 ③ 화면에 도장 목록을 따로 보여 주고, 운영자가 「같은 도장으로 묶기」를 할 수 있게 한다. 이름이 비슷한 도장 쌍은 묶기 후보로 띄운다. 이 판정을 잘못하면 실패 조건 1번으로 바로 이어지므로, 대진을 만들기 전에 도장 목록을 한 번 보여 준다.

**샘플 문서를 아직 받지 못했다.** 양식은 「보통 비슷하다」고만 들었다. 그래서 리더는 표의 머리글을 **허용된 동의어 목록**과 맞춰 칸을 찾는다. 예: 「성명·이름」, 「학년·나이·연령」. 동의어 목록은 한 곳에 상수로 둔다. 샘플이 오면 그 목록을 맞춘다. 칸을 찾지 못한 문서는 조용히 넘기지 않고 ③ 화면에 「읽지 못함」으로 띄운다.

### 5.2 구분(초·중·고·성인) 산출

1. 학년이 적혀 있으면 **적힌 학년을 그대로** 쓴다. 대회가 1~2월이어서 학년이 바뀌는 시기와 겹쳐도 보정하지 않는다. 신청서를 쓴 도장이 기준을 맞춘다고 본다. *(설계자 판단)* 「초3」「초등 3」「중1」「고2」 같은 표기를 인식한다. 「3학년」처럼 학교급이 없으면 추정하지 않고 「확인 필요」로 표시한다.
2. 학년이 없으면 **연 나이**(대회 연도 − 출생연도 기준 나이)로 계산한다.

   | 연 나이 | 8~13 | 14~16 | 17~19 | 20 이상 |
   |---|---|---|---|---|
   | 구분 | 초1~초6 | 중1~중3 | 고1~고3 | 성인 |

   8세 미만이면 「확인 필요」로 표시한다. 나이로 추정한 행은 ③ 화면에서 표시하고, 운영자가 고칠 수 있다.

### 5.3 부문 제약조건 (운영자가 정함)

부문은 **종목(개인/단체) × 성별(남/여/혼성) × 구분 범위**로 정한다. 예:
- 개인전 · 남 · 초1~초2
- 개인전 · 여 · 중1~중3
- 단체전 · 혼성 · 성인 · 팀 5명

- 구분 범위는 연속된 구분이다. 초1 하나만 둘 수도 있고, 초1~2, 초1~6 처럼 묶을 수도 있다. 학년이 아닌 「성인」은 하나의 구분으로 친다.
- 단체전 부문은 팀 인원을 부문마다 정한다.
- **소수 인원 합치기:** 부문마다(또는 대회 전체 기본값으로) 「N명(팀) 미만이면 인접 부문과 합친다」를 설정한다. 합칠 방향(위·아래)도 운영자가 고른다. 자동으로 합친 결과는 운영자에게 보여 주고 되돌릴 수 있게 한다.
  - **인접**은 같은 종목, 같은 성별 안에서 구분 범위가 바로 위나 아래로 이어지는 부문이다. 예: 초1~2 의 위는 초3~4. *(설계자 판단)*
  - 남녀를 합쳐 혼성으로 만드는 것은 자동으로 하지 않는다. 운영자가 처음부터 혼성 부문을 만들거나, 손으로 합친다.
  - 합친 뒤에도 N명 미만이면 같은 방향으로 한 번 더 합친다. 더 합칠 후보가 없으면 멈추고 경고한다.
- **성인은 하나의 구분이다.** 나이대별로 나누지 않는다(개발자 답변).
- 한 선수가 두 부문에 들어가면 경고한다. 개인전과 단체전에 함께 나가는 것은 정상이다.
- 부문 설정은 「설정 묶음」으로 저장해 다음 대회에서 다시 쓸 수 있게 한다. *(설계자 판단)*
- 단·급 같은 추가 기준은 이번 범위가 아니다. 그래도 나중에 제약조건 종류를 늘리기 쉬운 구조로 만든다. 개발자가 「제약으로 넣는 건 괜찮다」고 했다.

### 5.4 단체전 팀

신청서에 팀이 어떻게 적혀 오는지는 **아직 모른다.** 그래서 두 경로를 둔다.
- 문서에 팀 이름과 팀원이 적혀 있으면 그대로 읽는다.
- 적혀 있지 않으면 ③ 화면에서 운영자가 도장별로 선수를 골라 팀을 만든다.

팀의 도장은 팀원의 도장이다. 팀원 수가 부문의 팀 인원과 다르면 경고한다. 샘플을 받으면 첫 번째 경로를 구체화한다.

## 6. 대진 규칙

### 6.1 토너먼트

- 지면 탈락하는 단일 토너먼트다.
- 참가 수 N 에 대해 대진 크기는 N 이상인 가장 작은 2의 거듭제곱 P 로 잡는다. 부전승은 P − N 개다.
- 부전승은 표준 시드 순서 자리에 배치해 대진 전체에 고르게 흩어지게 한다. 이렇게 하면 부전승끼리 맞붙는 일이 없다.
- 3위: 공동 3위다. 준결승에서 진 두 쪽이 모두 3위이고 3위 결정전은 없다. *(2026-11-12 개발자 지시 — 결정전 번호가 끼면 결승 번호가 하나 비어 보였다)*
- 참가자가 1명이면 대진 없이 「단독 출전」으로 표시한다. 0명인 부문은 만들지 않는다.

### 6.2 같은 도장 분리

목표는 같은 도장끼리 **가능한 한 늦은 라운드에서** 만나게 하는 것이다.

1. 인원이 많은 도장부터 처리한다. 도장마다 순서를 무작위로 섞는다.
2. 그 도장의 선수를 대진의 절반, 4분의 1, 8분의 1 … 구역에 고르게 나눠 넣는다. 각 단계에서 그 도장 선수가 가장 적은 구역을 고르고, 동률이면 무작위로 고른다.
3. 남은 자리는 나머지 도장 선수로 같은 방식으로 채운다.
4. 한 도장이 절반을 넘으면 1회전 대결을 피할 수 없다. 이때는 피할 수 없는 만큼만 붙이고, 해당 경기를 화면과 출력 미리보기에서 표시한다. 출력물 자체에는 표시하지 않는다. *(설계자 판단)*

- 추첨에 쓴 난수 시드를 대회 파일에 저장해 같은 결과를 다시 만들 수 있게 한다.
- 검증 함수는 「같은 도장끼리 처음 만나는 라운드」를 경기마다 계산하고, 1회전 대결 목록을 돌려준다. 수정 화면의 경고도 이 함수를 쓴다.

### 6.3 대진표 모양과 번호 — 개발자가 보낸 예시 기준 (2026-11-12)

개발자가 대진표 예시를 두 장 보냈다. 첫 장(64명, 블록마다 번호를 다시 매김)은 개발자가 「순서를 잘못 말했다」며 두 번째 장으로 바로잡았다. **두 번째 예시(남자 단부 개인전 B조, 26명, A4 세로)가 기준**이다. 모양은 따르되 **더 깔끔하고 깨끗하게** 그린다.

- **경기 번호:** 대진 전체에 걸쳐 이어서 매긴다. 부전승이 낀 칸에는 번호가 없다. 26명 예시는 아래와 같다.
  - 1회전: 왼쪽 위→아래 1~5, 이어서 오른쪽 위→아래 6~10
  - 2회전: 왼쪽 11~14, 오른쪽 15~18
  - 3회전: 왼쪽 19~20, 오른쪽 21~22
  - 4회전: 왼쪽 23, 오른쪽 24
  - 결승: 25
- **선수 번호는 넣지 않는다**(개발자 지시: 「이름 옆에 번호는 필요 없고 저 토너먼트 경기 순서」). 번호는 경기 번호뿐이다.
- **배치:**
  - 왼쪽은 `(도장명) 이름` 다음에 대진 선을 긋고, 오른쪽은 거울상으로 `이름 (도장명)` 이다.
  - 선수 한 명이 한 줄을 차지하고 줄 간격은 고르다. 부전승은 줄을 차지하지 않는다.
  - 부전승인 선수는 1회전 없이 선을 다음 라운드까지 바로 잇는다.
  - 경기 번호는 두 선이 만나는 세로선 바로 옆에 쓴다.
  - 결승은 가운데 세로선으로 그리고, 양쪽 마지막 경기 번호(예: 23·24)를 그 옆에 둔다.
  - 맨 위에 부문 제목(예: 「남자 단부 개인전 B조」)을 단다. 제목은 성별·나이(구분)·종목·조 같은 항목으로 이루어진다. 기본값은 부문 이름에서 만들고, **운영자가 항목을 고르거나 직접 고쳐 쓴다**(개발자 지시).
- **「조」 나누기**(한 부문을 A조·B조로 나눠 여러 장에 싣는 것)의 규칙은 아직 모른다. 이번에는 제목만 바꿀 수 있게 하고, 조를 자동으로 나누지는 않는다. *(설계자 판단)*

## 7. 출력

- 용지는 **항상 A4**다. 한 부문이 한 장에 들어가지 않으면 여러 장으로 나눈다.
  - 왼쪽 절반과 오른쪽 절반을 각 장에 싣는다.
  - 그래도 넘치면 구역별로 나누고, 장마다 「○쪽에서 이어짐」을 표시한다. 글자가 정해 둔 최소 크기보다 작아지면 장을 나누는 방식이다.
  - 구현에서 정한 값 *(설계자 판단)*:
    - A4 세로로 쓴다.
    - 글자는 7~16pt 사이에서 인원에 맞춰 커지거나 작아지고, 줄 간격은 최대 34mm 다.
    - 이름 칸 너비는 가장 긴 「(도장) 이름」에 맞춘다.
    - 양쪽 마지막 경기 높이를 맞춰 결승을 곧은 한 줄로 긋는다.
    - 화면 미리보기와 PDF 는 같은 좌표(`domain/layout`)를 쓴다.
- 장마다 넣는 내용은 **부문 제목 · 도장명 · 이름 · 경기 번호뿐**이다(개발자 지시). 대회명·날짜·지역·선수 번호는 넣지 않는다.
- **운영자가 한글에서 글자를 고칠 수 있어야 한다**(개발자 답변).
  - 이름·도장명·경기 번호·제목은 한글에서 눌러 고칠 수 있는 글상자(또는 표 칸)로 넣는다.
  - 대진 선은 도형(선)으로 그린다.
  - 고친 내용은 프로그램으로 다시 가져오지 않는다. 출력 이후의 한글 편집은 운영자 몫이다. *(설계자 판단)*
- `.hwpx` 와 PDF 는 **같은 좌표 계산(layout)**에서 나온다. 화면 미리보기도 같은 계산을 쓴다. 셋이 어긋나지 않게 하려는 것이다.
- 한글 버전은 모르므로 최신 한글을 기준으로 한다. 운영자 PC 에서 `.hwpx` 가 열리는지는 **설치 후 실제로 확인해야 하는 항목**이다. 아직 확인하지 않았다.
- PDF 에는 한글 글꼴을 넣어야 한다. 배포에 쓸 수 있는 글꼴의 라이선스는 구현 때 확인한다. 예: 나눔고딕, 본고딕.

## 8. 구조 — 계층형 아키텍처 (개발자 지시)

```
presentation  ──▶  application  ──▶  domain
                                       ▲
                  infrastructure ──────┘  (domain/ports.py 의 인터페이스를 구현)
```

```
KendoTournament/
 ├─ pyproject.toml
 ├─ src/kendo_tournament/
 │   ├─ presentation/      PySide6 화면 (대회 · 불러오기/명단 · 부문 · 대진 보기/수정 · 출력)
 │   ├─ application/       유스케이스: import_roster · build_divisions · draw_brackets · edit_bracket · export_brackets
 │   ├─ domain/            순수 파이썬, 외부 부품 import 금지
 │   │   ├─ model/          선수 · 팀 · 도장 · 대회 · 부문 · 대진 · 경기
 │   │   ├─ division/       구분 산출 · 부문 제약조건 · 소수 인원 합치기
 │   │   ├─ draw/           추첨 · 같은 도장 분리 · 부전승 · 경기 번호 · 검증
 │   │   ├─ layout/         대진표 좌표 계산 (화면 · hwpx · pdf 공용)
 │   │   └─ ports.py        RosterReader · BracketExporter · TournamentRepository
 │   ├─ infrastructure/
 │   │   ├─ readers/        docx · hwp · hwpx · pdf 리더 + 확장자→리더 등록표
 │   │   ├─ exporters/      hwpx · pdf
 │   │   └─ storage/        대회 파일 (JSON)
 │   └─ main.py            구체 클래스 조립 · 시작점
 └─ tests/
     ├─ domain/             추첨 · 분리 · 부전승 · 번호 · 구분 산출 · 부문 규칙
     ├─ application/        워드 샘플로 불러오기 → 출력 끝까지
     └─ infrastructure/     형식별 읽기 · 쓰기
```

- 의존은 위에서 아래로만 흐른다. domain 은 PySide6 · 파일 부품을 모른다.
- 구체 클래스는 `main.py` 에서만 만들어 연결한다.
- 리더는 형식마다 하나씩 두고 등록표로 고른다. 형식이 4개라 if/else 대신 등록표를 쓴다.
- 대진 추첨은 난수 공급원을 주입받는다. 그래야 시험에서 결과를 고정할 수 있다.

## 9. 시험과 완료 기준

- **domain 단위 시험:** 참가 수 1~64 전부에서 다음을 확인한다.
  - 부전승끼리 맞붙지 않는다.
  - 분리가 가능한 경우에는 같은 도장이 1회전에서 만나지 않는다.
  - 경기 번호가 빠짐없이 이어진다.
  - 연 나이 → 구분 경계값이 맞는다(7·8·13·14·16·17·19·20세).
  - 부문 합치기 규칙이 맞는다(연속 합치기, 후보가 없을 때 포함).
  - 기권 빼기와 늦은 신청 끼워 넣기 뒤에도 나머지 칸이 그대로다.
  - 도장명 정규화와 묶기가 맞는다.
- **application 시험:** 가짜 이름으로 만든 워드 신청서 여러 장을 넣어 `.hwpx` 와 PDF 가 나오는지 확인한다.
- **infrastructure 시험:**
  - 형식별 리더를 시험한다. `.hwp` · `.pdf` 는 샘플을 받은 뒤 추가한다.
  - 만든 `.hwpx` 를 다시 열어 구조가 유효한지 확인한다.
- **완료:** 아래를 모두 마쳐야 완료다.
  1. exe 를 만든다.
  2. 개발 PC 에서 처음부터 끝까지 한 번 돌린다.
  3. 운영자 PC 에 설치해 `.hwpx` 를 한글로 열고 PDF 를 인쇄해 본다.
