# 검도 대회 대진표 프로그램

검도 대회 참가 신청서를 읽어 **부문 나누기 → 추첨 → 대진표 책자 PDF 출력**까지 한 번에 처리하는 Windows 데스크톱 프로그램입니다.

대회를 운영하다 보면 도장마다 한글·워드·PDF로 제각각 보내 온 신청서를 손으로 옮겨 적고, 대진표를 직접 그리는 데 많은 시간이 듭니다. 이 프로그램은 그 반복 작업을 없애고, 운영자는 결과를 확인하고 필요한 곳만 고치면 되도록 만들었습니다.

## 주요 기능

- **신청서 읽기** — 한글(`.hwp`·`.hwpx`), 워드(`.docx`), PDF 신청서에서 선수 명단을 직접 읽습니다. 한글 프로그램이 설치돼 있지 않아도 됩니다.
- **부문 자동 나누기** — 신청서의 종별(학교급·학년·성별·나이 구간)에 따라 개인전·단체전 부문을 나누고, 부전승이 생기는 부문은 이웃 부문과 합치기를 권합니다.
- **추첨과 대진 만들기** — 같은 도장 선수는 최대한 늦게 만나도록 흩어 놓고, 부전승은 꼭 필요한 만큼만 둡니다. 경기 번호는 빠짐없이 이어지고 결승이 마지막 경기입니다.
- **손으로 고치기** — 추첨이 끝난 뒤에도 선수를 옮기거나 끼워 넣을 수 있고, 같은 도장끼리 일찍 만나는 자리는 알려 줍니다.
- **작성 실수 찾기** — 같은 선수가 두 번 적힌 것 같은 의심 사례를 보여 줘 서류와 대조할 수 있습니다.
- **대진표 책자 출력** — A4 대진표, 표지, 식순·인사말·경기 일정 쪽을 묶어 인쇄용 PDF로 만듭니다.
- **대회 파일 저장** — 작업 중인 대회를 `.kendo` 파일로 저장했다가 다시 열 수 있습니다.

## 기술 스택

| 영역 | 사용 기술 |
| --- | --- |
| 언어 | Python 3.13 |
| 화면 | PySide6 (Qt Widgets) |
| 신청서 읽기 | python-docx · olefile · pdfplumber · hwpx 직접 해석(zip/xml) |
| PDF 출력 | reportlab · Pretendard 글꼴 |
| 시험 | pytest · ruff |
| 배포 | PyInstaller (실행 파일 한 개) |

## 구조

대회 규칙(부문·추첨·번호·배치)은 화면이나 파일 처리와 섞이지 않도록 계층을 나눴습니다.

```text
presentation  →  application  →  domain  ←  infrastructure
(PySide6 화면)    (유스케이스)     (대회 규칙)   (신청서 읽기 · PDF 출력 · 저장)
```

- `domain/` 은 순수 파이썬이라 외부 라이브러리 없이 단위 시험으로 검증합니다.
- 새 신청서 형식은 `infrastructure/readers/` 에 reader 하나를 추가하고 등록만 하면 됩니다.
- 구체 클래스를 서로 잇는 곳은 `main.py` 한 곳뿐입니다.

## 실행

```bash
python -m venv .venv
.venv\Scripts\pip install -e .[dev]

.venv\Scripts\python -m kendo_tournament.main   # 프로그램 실행
.venv\Scripts\python -m pytest -q               # 시험
build_release.bat                               # dist\KendoTournament.exe 생성
```
